SIMPLY PUT, this app helps the avarege consumer track their habits using the Pixela API.
Because pixela is an API, normally, if you wanted to track your habits, you would have to know how to code.
Pixaplan gets rid of this, with an easy GUI, helps normal everyday people use Pixela, no code needed.


The MainMenu.py file opens the Main Menu. You can log into pixela, sign up to pixela, record your habits, make a graph, go to settings, and much much more.
However, it's not always convenient to have to go through the main menu each time you want to record what you did today, so that's where the AddRecording.py file comes into play.
AddRecording.py opens up a simple console where you can record your habit for today and add it to your graph.


FIRST TIME? Let's make your first graph. First create an account by opening up the main menu and pressing "Create Account".
Then, press "Create Graph". Fill out the ID, your goal, and your units. For example, if I wanted to track my cycling, I would put "graph1" (any id), "cycling", and "miles".
Opening the GoToGraph.py file will open your MOST RECENT graph.
To open another graph, use the Go To Graph button in the main menu and specify the ID.


To add a recording, you can either use the "add recording" button in the main menu or use the AddRecording.py file to add it faster.
Adding a recording records how much of a habit you did today. For example, I would press "Add Recording" then record that I cycled 2 miles today.
